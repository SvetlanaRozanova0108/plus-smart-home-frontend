# Plus Smart Home Frontend

Веб-приложение интернет-магазина умных устройств Plus Smart Home. Проект разработан на React с использованием современного стека технологий и реализует все базовые паттерны работы с компонентами, данными и состоянием.

## Технологический стек

- **React** 18.3.1 - библиотека для построения пользовательского интерфейса
- **React Router DOM** 6.26.2 - маршрутизация в приложении
- **Vite** 5.4.8 - сборщик и dev-сервер
- **Bootstrap** 5.3.3 + **React Bootstrap** 2.10.5 - UI-фреймворк
- **Framer Motion** 11.11.11 - анимации
- **JavaScript (ES Modules)**

## Структура проекта

```
src/
├── api/                # API-клиент для работы с бэкендом
├── assets/             # Статические ресурсы (иконки, изображения)
├── components/         # React-компоненты
│   ├── containers/     # Контейнерные компоненты (логика)
│   ├── hoc/           # Компоненты высшего порядка (HOC)
│   ├── presentational/# Презентационные компоненты (UI)
│   └── ...            # Прочие компоненты
├── context/           # React Context (корзина)
├── data/              # Данные приложения
│   ├── json/          # JSON-файлы с данными (разбитые по каталогам)
│   └── catalogLoader.js # Загрузчик JSON-данных
├── hooks/             # Кастомные хуки
├── pages/             # Страницы приложения
├── styles/            # CSS-стили
└── utils/             # Вспомогательные функции
```

## Реализованные паттерны и требования

### Основы React
- **useState** - управление локальным состоянием компонентов
- **useEffect** - работа с побочными эффектами
- **Кастомные хуки** - `useFetchData`, `useProducts`, `useLocalStorage` для переиспользования логики
- **Context API** - `CartContext` для управления корзиной покупок

### Работа с данными
- **try/catch/finally** - обработка асинхронных запросов во всех API-вызовах
- **Loading/Error/Empty/Success состояния** - для всех компонентов, работающих с данными
- **Fallback-данные** - при ошибке загрузки с сервера используются локальные данные

### Архитектура компонентов
- **Контейнер/презентация** - разделение логики и отображения (например, `CatalogContainer` / `CatalogList`)
- **Компоненты, получающие данные через props** - презентационные компоненты
- **Рендеринг списков** - использование `map()` для преобразования массивов в JSX
- **Компонент карточки** - переиспользуемый `ProductCard` для разных товаров

### Продвинутые паттерны
- **HOC (Higher-Order Components)** - `withLoading`, `withErrorBoundary`
- **Render Props** - компонент `DataProvider` с поддержкой render/children функций
- **Event handlers** - `onClick`, `onChange`, `onSubmit`, `onClose`, `onSelect`
- **Framer Motion** - анимации при рендеринге и взаимодействии

### Структура данных
- **Разделение данных** - `catalog.js` разбит на отдельные JSON-файлы в `src/data/json/`
- **Сквозная нумерация ID** - все элементы в JSON имеют уникальные ID от 1 по порядку
- **Статические файлы в public/** - изображения и иконки перенесены из `src/assets/` в `public/images/` и `public/icons/`, папка `assets` удалена

## Установка и запуск

### Требования
- Node.js 16+ 
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для продакшена
```bash
npm run build
```

### Предпросмотр продакшен-сборки
```bash
npm run preview
```

## Основные страницы

- `/` - Главная страница с категориями, хитами продаж, сценариями
- `/catalog` - Каталог товаров с фильтрацией, поиском и сортировкой
- `/product/:productId` - Страница товара с описанием, характеристиками, отзывами
- `/cart` - Корзина покупок
- `/scenarios` - Готовые сценарии умного дома
- `/scenarios/:slug` - Детальная страница сценария
- `/delivery` - Информация о доставке
- `/contacts` - Контакты
- `*` - Страница 404

## Особенности реализации

- **Адаптивный дизайн** - работает на всех устройствах
- **Сохранение корзины** - данные корзины сохраняются в localStorage
- **Фильтрация и поиск** - в каталоге реализованы фильтры по категориям, поиск, сортировка
- **Модальные окна** - оформление заказа через модальное окно
- **Анимации** - плавные переходы с использованием Framer Motion
- **Оптимизация** - lazy loading изображений, мемоизация вычислений

## API

Приложение работает с REST API. Базовый URL настраивается через переменную окружения `VITE_API_BASE`. При недоступности API используются fallback-данные из JSON-файлов.
